# 3号路口：三相位方向灯方案（东西合并）

## 一、路口概述

- **类型**：十字路口，东西方向左转+直行合并为一个相位
- **总周期**：108 秒（5 相位：GREEN→YELLOW→ALLRED→RED→YELLOW2）
- **相位**：3 个相位（EW → NS_Straight → NS_Left）
  - **EW**：东西左转 + 直行合并，绿灯 50s
  - **NS_Straight**：南北直行，绿灯 20s
  - **NS_Left**：南北左转，绿灯 20s
- **南北右转不受控**：在 NS_Straight 和 NS_Left 相位中均有放行窗口，无需 locker

## 二、配时方案

### 图例说明

每个相位图例格式：🟢 绿灯时长 / 🟡 黄灯 3s / 🔴 全红 3s + 红灯 / 🟡 黄闪2 3s

### 3 个相位

| 相位 | 放行方向 | 绿灯 | 黄闪 | 全红 | 红灯 | 黄闪2 | 总周期 |
|:----:|---------|:----:|:----:|:----:|:----:|:----:|:------:|
| **EW** | **东西左转 + 直行** | 50s | 3s | 3s | 49s | 3s | 108s |
| **NS_S** | **南北直行** | 20s | 3s | 3s | 79s | 3s | 108s |
| **NS_L** | **南北左转** | 20s | 3s | 3s | 79s | 3s | 108s |

> **南北右转**：在 NS_S 和 NS_L 两个相位中均有放行窗口，因此**不受信号灯控制**，AGV 右转始终自由通行。

## 三、配时叠加验证

```
EW（东西左转+直行）：50s 绿→3s黄→3s全红→49s红→3s黄闪2 = 108s
NS_S（南北直行）：   20s 绿→3s黄→3s全红→79s红→3s黄闪2 = 108s
NS_L（南北左转）：   20s 绿→3s黄→3s全红→79s红→3s黄闪2 = 108s
```

```
├── red
├── green

```

## 五、标签配置

每个相位灯添加以下标签：

| 标签名 | 类型 | Phase_EW | Phase_NS_S | Phase_NS_L |
|--------|------|:--------:|:----------:|:----------:|
| `绿灯时长` | number | 50 | 20 | 20 |
| `黄闪时长` | number | 3 | 3 | 3 |
| `全红时长` | number | 3 | 3 | 3 |
| `红灯时长` | number | 49 | 79 | 79 |
| `偏移时间` | number | **0** | **56** | **82** |
| `phase` | string | GREEN | GREEN | GREEN |

> **偏移时间计算**（EW→NS_S→NS_L 连续排列，周期 108s）：
> - EW 偏移 = 0
> - NS_S 偏移 = EW(绿灯50 + 黄闪3 + 全红3) = 56
> - NS_L 偏移 = 56 + NS_S(绿灯20 + 黄闪3 + 全红3) = 82
>
> **校验**：NS_L 的 GREEN = [82, 102)，结束于 102 → YELLOW+ALLRED = 6s → 下一周期 EW 从 108 开始 ✅
>
> 红灯时长验证：
> - EW：108 − 50 − 3 − 3 − 3 = 49 ✓
> - NS_S：108 − 20 − 3 − 3 − 3 = 79 ✓
> - NS_L：108 − 20 − 3 − 3 − 3 = 79 ✓

## 六、全局函数（复用或新增）

```cpp
void setLightColor2(Object light, string state) {
    treenode redLight = light.find("red");
    treenode greenLight = light.find("green");
    treenode yellowLight = light.find("yellow");

    if (state == "GREEN") {
        if (greenLight) greenLight.color = Color(0, 1, 0, 1);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 0.3);
        if (redLight) redLight.color = Color(1, 0, 0, 0.3);
    } else if (state == "YELLOW" || state == "YELLOW2") {
        if (greenLight) greenLight.color = Color(0, 1, 0, 0.3);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 1);
        if (redLight) redLight.color = Color(1, 0, 0, 0.3);
    } else {  // ALLRED 或 RED
        if (greenLight) greenLight.color = Color(0, 1, 0, 0.3);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 0.3);
        if (redLight) redLight.color = Color(1, 0, 0, 1);
    }
}
```

>如果 1 号或 2 号路口已经定义过 `setLightColor2`，不用重复，直接用已有的。（3 号路口 3 灯通用）

## 七、OnModelStart（3 个相位灯通用）

```cpp
Object light = ownerobject(c);

double greenDur = light.labels["绿灯时长"].value;
double flashDur = light.labels["黄闪时长"].value;
double allRedDur = light.labels["全红时长"].value;
double redDur = light.labels["红灯时长"].value;
double offset = light.labels["偏移时间"].value;

double totalCycle = greenDur + flashDur + allRedDur + redDur + flashDur;
double t = fmod(offset, totalCycle);

string state; double remaining;
if (t < greenDur) {
    state = "GREEN";
    remaining = greenDur - t;
} else if (t < greenDur + flashDur) {
    state = "YELLOW";
    remaining = (greenDur + flashDur) - t;
} else if (t < greenDur + flashDur + allRedDur) {
    state = "ALLRED";
    remaining = (greenDur + flashDur + allRedDur) - t;
} else if (t < greenDur + flashDur + allRedDur + redDur) {
    state = "RED";
    remaining = (greenDur + flashDur + allRedDur + redDur) - t;
} else {
    state = "YELLOW2";
    remaining = totalCycle - t;
}

light.labels["phase"].value = state;
setLightColor2(light, state);
senddelayedmessage(light, remaining, current, state);
```

## 八、OnMessage（3 个相位灯通用）

```cpp
Object light = ownerobject(c);
string state = msgparam(1);

double greenDur = light.labels["绿灯时长"].value;
double flashDur = light.labels["黄闪时长"].value;
double allRedDur = light.labels["全红时长"].value;
double redDur = light.labels["红灯时长"].value;

string nextState; double delay;
if (state == "GREEN") {
    nextState = "YELLOW";
    delay = flashDur;
} else if (state == "YELLOW") {
    nextState = "ALLRED";
    delay = allRedDur;
} else if (state == "ALLRED") {
    nextState = "RED";
    delay = redDur;
} else if (state == "RED") {
    nextState = "YELLOW2";
    delay = flashDur;
} else {
    nextState = "GREEN";
    delay = greenDur;
}

light.labels["phase"].value = nextState;
setLightColor2(light, nextState);
senddelayedmessage(light, delay, current, nextState);
```

## 十、占用模块：3 套 Locker（EW / NS_S / NS_L）

与 1 号、2 号路口不同，3 号路口东西方向的左转和直行**合并为同一个相位灯**，因此东西方向只需 1 套 Locker 控制全部东西路径。

### Locker 和 Group 清单

| Locker 实体 | 控制范围 | 放行时机 | Group |
|------------|---------|---------|-------|
| `Locker_EW` | 东西方向所有冲突区（左转+直行） | Phase_EW GREEN | `Group_EW` |
| `Locker_NS_S` | 南北直行冲突区 | Phase_NS_S GREEN | `Group_NS_S` |
| `Locker_NS_L` | 南北左转冲突区 | Phase_NS_L GREEN | `Group_NS_L` |

> **南北右转不控**：右转在 Phase_b 和 Phase_d 均有窗口，因此右转路径上不需要 ControlArea，AGV 右转自由通行。

### Group 内容（你在路面上添加的 ControlArea）

| Group | 放入的 ControlArea |
|-------|-------------------|
| `Group_EW` | 东/西进口左转 + 东/西进口直行 路径上的所有冲突区域 |
| `Group_NS_S` | 南/北进口直行 路径上的冲突区域 |
| `Group_NS_L` | 南/北进口左转 路径上的冲突区域 |

### 初始化锁定脚本（放在 Model 的 OnModelStart 或独立触发器）

```cpp
// ===== 3号路口初始化：ALL_RED 锁定 3 个方向 =====

// 1. 将 3 个相位灯设为 ALLRED
string lightNames[3] = {"Phase_EW","Phase_NS_S","Phase_NS_L"};
for (int i = 0; i < 3; i++) {
    Object light = Model.find(lightNames[i]);
    if (light) light.labels["phase"].value = "ALLRED";
}

// 2. 锁定 3 个方向的冲突区域
string lockerNames[3] = {"Locker_EW","Locker_NS_S","Locker_NS_L"};
string groupNames[3] = {"Group_EW","Group_NS_S","Group_NS_L"};

for (int k = 0; k < 3; k++) {
    Object locker = Model.find(lockerNames[k]);
    Group grp = Group(groupNames[k]);
    if (!locker) continue;

    for (int i = 1; i <= grp.length; i++) {
        Object caObj = grp[i];
        if (!caObj) continue;
        AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);

        int locked = 0;
        for (int j = 1; j <= ca.allocations.length; j++)
            if (ca.allocations[j].allocator == locker) { locked = 1; break; }
        if (!locked)
            for (int j = 1; j <= ca.requests.length; j++)
                if (ca.requests[j].allocator == locker) { locked = 1; break; }
        if (!locked) ca.allocate(locker, 1);
    }
}
```

## 十一、ProcessFlow 通行控制

### 结构

```
主流程
├── 子流程 EW（监听 Phase_EW）
├── 子流程 NS_S（监听 Phase_NS_S）
└── 子流程 NS_L（监听 Phase_NS_L）
```

### PF 子流程：EW（Phase_EW — 东西左转+直行）

```cpp
Object light = Model.find("Phase_EW");
Object locker = Model.find("Locker_EW");
Group grp = Group("Group_EW");

while (true) {
    if (light.labels["phase"].value == "GREEN") {
        pt("3号路口 东西方向 放行");
        for (int i = 1; i <= grp.length; i++) {
            Object caObj = grp[i];
            if (caObj) caObj.as(AGV.AllocatableObject).deallocate(locker);
        }
        while (light.labels["phase"].value == "GREEN") sleep(0.05);
        pt("3号路口 东西方向 锁定");
        for (int i = 1; i <= grp.length; i++) {
            Object caObj = grp[i];
            if (!caObj) continue;
            AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);
            int locked = 0;
            for (int j = 1; j <= ca.allocations.length; j++)
                if (ca.allocations[j].allocator == locker) { locked = 1; break; }
            if (!locked) ca.allocate(locker, 1);
        }
    }
    sleep(0.05);
}
```

## 十二、各通行方向的状态对应关系

| 通行方向 | Phase_EW GREEN | Phase_NS_S GREEN | Phase_NS_L GREEN |
|---------|:--------------:|:----------------:|:----------------:|
| 东西左转 + 直行 | ✅ 放行 | ❌ 锁定 | ❌ 锁定 |
| 南北直行 | ❌ 锁定 | ✅ 放行 | ❌ 锁定 |
| 南北左转 | ❌ 锁定 | ❌ 锁定 | ✅ 放行 |
| 南北右转 | ❌ 锁 | ✅ 无锁自由 | ✅ 无锁自由 |

> 南北右转路径上**不加 ControlArea**，始终自由通行。

## 十五、常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 偏移时间导致灯同时亮 | 偏移值算错 | 校验：EW 偏移 0、NS_S 偏移 56（50+3+3）、NS_L 偏移 82（56+20+3+3） |
| 南北右转的 AGV 被锁 | 右转路径上有 ControlArea | 从右转路径移除 ControlArea，或将其从所有 Group 中排除 |
| 周期不满 108s | senddelayedmessage 浮点漂移 | 可选优化：定期用 `fmod(time(), 108)` 校准 |
| Group 里找不到 CA | ControlArea 未正确添加 | 用 Model.find 确认 CA 名称，确保已加入 Group |
