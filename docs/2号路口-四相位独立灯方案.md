# 2号路口：四相位独立灯方案

## 一、路口概述

- **类型**：南港八路南北向 + 自由港大道东西向，十字路口
- **总周期**：117 秒
- **灯数量**：4 个独立灯（A/C/B/D），各自独立轮转
- **相位状态**：5 态（GREEN → YELLOW → ALLRED → RED → YELLOW2 → GREEN 循环）

---

## 二、配时方案（修正后 117s 精确周期）

| 路口 | 绿灯 | 黄闪 | 全红 | 红灯 | 黄闪2 | 合计 | 偏移 |
|------|------|------|------|------|-------|------|------|
| A | 30s | 2s | 2s | 81s | 2s | 117s | 0s |
| C | 18s | 2s | 2s | 93s | 2s | 117s | 34s |
| B | 35s | 2s | 2s | 76s | 2s | 117s | 56s |
| D | 18s | 2s | 2s | 93s | 2s | 117s | 95s |

> **注意**：红灯值已按 117s 周期修正。原表格 83/95/78/95 会有 2s 偏差，统一减 2s。

## 三、实体结构

每个灯用 1 个 **TaskExecuter**，内部放 3 个 **drawsurrogate** 子实体。共 4 个灯实体：

```
TrafficLight_A
├── red      (drawsurrogate)
├── green    (drawsurrogate)
└── yellow   (drawsurrogate)

TrafficLight_C  （同上结构）
TrafficLight_B  （同上结构）
TrafficLight_D  （同上结构）
```

| 标签名 | 类型 | A 值 | C 值 | B 值 | D 值 |
|--------|------|------|------|------|------|

| `黄闪时长` | number | 2 | 2 | 2 | 2 |
| `全红时长` | number | 2 | 2 | 2 | 2 |
| `红灯时长` | number | 81 | 93 | 76 | 93 |
| `偏移时间` | number | 0 | 34 | 56 | 95 |
| `phase` | string | GREEN | GREEN | GREEN | GREEN |

## 五、全局函数（Model → Scripts → Global Code）

```cpp
void setLightColor2(Object light, string state) {
    treenode redLight = light.find("red");
    treenode greenLight = light.find("green");
    treenode yellowLight = light.find("yellow");

    if (state == "GREEN") {
        if (greenLight) greenLight.color = Color(0, 1, 0, 1);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 0.3);
        if (redLight) redLight.color = Color(1, 0, 0, 0.3);
    } else if (state == "YELLOW" || state == "YELLOW2") {
        if (greenLight) greenLight.color = Color(0, 1, 0, 0.3);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 1);
        if (redLight) redLight.color = Color(1, 0, 0, 0.3);
    } else {  // ALLRED 或 RED
        if (greenLight) greenLight.color = Color(0, 1, 0, 0.3);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 0.3);
        if (redLight) redLight.color = Color(1, 0, 0, 1);
    }
}
```

## 六、OnModelStart（4 个灯通用，直接粘贴）

```cpp
Object light = ownerobject(c);

double greenDur = light.labels["绿灯时长"].value;
double flashDur = light.labels["黄闪时长"].value;
double allRedDur = light.labels["全红时长"].value;
double redDur = light.labels["红灯时长"].value;
double offset = light.labels["偏移时间"].value;

double totalCycle = greenDur + flashDur + allRedDur + redDur + flashDur;
double t = fmod(offset, totalCycle);

string state; double remaining;
if (t < greenDur) {
    state = "GREEN";
    remaining = greenDur - t;
} else if (t < greenDur + flashDur) {
    state = "YELLOW";
    remaining = (greenDur + flashDur) - t;
} else if (t < greenDur + flashDur + allRedDur) {
    state = "ALLRED";
    remaining = (greenDur + flashDur + allRedDur) - t;
} else if (t < greenDur + flashDur + allRedDur + redDur) {
    state = "RED";
    remaining = (greenDur + flashDur + allRedDur + redDur) - t;
} else {
    state = "YELLOW2";
    remaining = totalCycle - t;
}

light.labels["phase"].value = state;
setLightColor2(light, state);
senddelayedmessage(light, remaining, current, state);
```

## 七、OnMessage（4 个灯通用，直接粘贴）

```cpp
Object light = ownerobject(c);
string state = msgparam(1);

double greenDur = light.labels["绿灯时长"].value;
double flashDur = light.labels["黄闪时长"].value;
double allRedDur = light.labels["全红时长"].value;
double redDur = light.labels["红灯时长"].value;

string nextState; double delay;
if (state == "GREEN") {
    nextState = "YELLOW";
    delay = flashDur;
} else if (state == "YELLOW") {
    nextState = "ALLRED";
    delay = allRedDur;
} else if (state == "ALLRED") {
    nextState = "RED";
    delay = redDur;
} else if (state == "RED") {
    nextState = "YELLOW2";
    delay = flashDur;
} else {  // YELLOW2
    nextState = "GREEN";
    delay = greenDur;
}

light.labels["phase"].value = nextState;
setLightColor2(light, nextState);
senddelayedmessage(light, delay, current, nextState);
```

## 九、占用模块配置

### 方案：2 套 Locker（推荐）

A 和 C 都是南港八路南北向，B 和 D 都是自由港大道东西向，放行时间不重叠。可以用 2 套 Locker 覆盖 4 个灯。

### 实体清单

| 实体 | 类型 | 名称 |
|------|------|------|
| Locker NS | Locker | `TrafficLightLocker_NS` |
| Locker EW | Locker | `TrafficLightLocker_EW` |
| Group NS | Group | `NS_Stop_CA_Group` |
| Group EW | Group | `EW_Stop_CA_Group` |

### Group 内容

- **NS_Stop_CA_Group**：放南北方向（南港八路）A/C 路口的 AGV 路径上的所有 ControlArea
- **EW_Stop_CA_Group**：放东西方向（自由港大道）B/D 路口的 AGV 路径上的所有 ControlArea

### 初始化锁定脚本（放在 Model 的 OnModelStart 或一个独立触发器）

```cpp
// ===== 2号路口初始化：ALL_RED 锁定 =====

// 1. 将 4 个灯设为 ALLRED
string lightNames[4] = {"TrafficLight_A","TrafficLight_C","TrafficLight_B","TrafficLight_D"};
for (int i = 0; i < 4; i++) {
    Object light = Model.find(lightNames[i]);
    if (light) light.labels["phase"].value = "ALLRED";
}

// 2. 锁定 NS 方向
Object lockerNS = Model.find("TrafficLightLocker_NS");
Object lockerEW = Model.find("TrafficLightLocker_EW");
Group groupNS = Group("NS_Stop_CA_Group");
Group groupEW = Group("EW_Stop_CA_Group");

// 锁定 NS
if (lockerNS) {
    for (int i = 1; i <= groupNS.length; i++) {
        Object caObj = groupNS[i];
        if (!caObj) continue;
        AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);
        int locked = 0;
        for (int j = 1; j <= ca.allocations.length; j++)
            if (ca.allocations[j].allocator == lockerNS) { locked = 1; break; }
        if (!locked)
            for (int j = 1; j <= ca.requests.length; j++)
                if (ca.requests[j].allocator == lockerNS) { locked = 1; break; }
        if (!locked) ca.allocate(lockerNS, 1);
    }
}

// 锁定 EW
if (lockerEW) {
    for (int i = 1; i <= groupEW.length; i++) {
        Object caObj = groupEW[i];
        if (!caObj) continue;
        AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);
        int locked = 0;
        for (int j = 1; j <= ca.allocations.length; j++)
            if (ca.allocations[j].allocator == lockerEW) { locked = 1; break; }
        if (!locked)
            for (int j = 1; j <= ca.requests.length; j++)
                if (ca.requests[j].allocator == lockerEW) { locked = 1; break; }
        if (!locked) ca.allocate(lockerEW, 1);
    }
}
```

## 十、ProcessFlow 通行控制

### 结构

```
主流程
├── 子流程 NS（轮询 A+C）
└── 子流程 EW（轮询 B+D）
```

### PF 子流程 NS —— 监听南北方向（A 路口 + C 路口）

```cpp
Object lightA = Model.find("TrafficLight_A");
Object lightC = Model.find("TrafficLight_C");
Object lockerNS = Model.find("TrafficLightLocker_NS");
Group groupNS = Group("NS_Stop_CA_Group");

while (true) {
    string phaseA = lightA.labels["phase"].value;
    string phaseC = lightC.labels["phase"].value;

    // A 或 C 任意一个 GREEN → 放行南北
    if (phaseA == "GREEN" || phaseC == "GREEN") {
        pt("2号路口 NS 方向放行");
        for (int i = 1; i <= groupNS.length; i++) {
            Object caObj = groupNS[i];
            if (caObj) caObj.as(AGV.AllocatableObject).deallocate(lockerNS);
        }
        // 等待两个都不是 GREEN
        while (lightA.labels["phase"].value == "GREEN"
            || lightC.labels["phase"].value == "GREEN") {
            sleep(0.05);
        }
        // 锁定 NS
        pt("2号路口 NS 方向锁定");
        for (int i = 1; i <= groupNS.length; i++) {
            Object caObj = groupNS[i];
            if (!caObj) continue;
            AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);
            int locked = 0;
            for (int j = 1; j <= ca.allocations.length; j++)
                if (ca.allocations[j].allocator == lockerNS) { locked = 1; break; }
            if (!locked) ca.allocate(lockerNS, 1);
        }
    }
    sleep(0.05);
}
```

## 十一、备选方案：4 套 Locker

如果 A 和 C 的冲突区域不完全重叠（比如不同车道），可拆为 4 套：

| Locker | 对应灯 | Group |
|--------|-------|-------|
| `TrafficLightLocker_A` | A | `A_Stop_CA_Group` |
| `TrafficLightLocker_C` | C | `C_Stop_CA_Group` |
| `TrafficLightLocker_B` | B | `B_Stop_CA_Group` |
| `TrafficLightLocker_D` | D | `D_Stop_CA_Group` |

PF 则用 4 个子流程，各自独立监听 1 个灯。结构与 2 套 Locker 的子流程相同，只将 A+C 的判断简化为单灯判断。

## 十三、常见问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 多个灯同时 GREEN | 偏移值算错 | 重新校验：A 偏移 0、C 偏移 34（30+2+2）、B 偏移 56（34+18+2+2）、D 偏移 95（56+35+2+2） |
| 灯颜色不变 | OnMessage 字符串匹配问题 | 检查 `state == "GREEN"` 等是否用双引号 |
| AGV 被永久锁住 | deallocate 未执行 | 检查 PF 子流程是否正确读到 phase |
| 时间累加后不准 | senddelayedmessage 浮点误差 | 用 `fmod(time(), totalCycle)` 定期校准（可选优化） |
