> **特点**：复制即用，只需改标签值，无需改代码。

## 1. 前置准备

确保模型中已有以下对象（AGV 路网的基本要素）：

- **ControlArea**：路口冲突区域（AGV 路网中的控制点），放入 Group 中管理
- **AGV 路网**：已配置 ControlArea 的 AGV 路径

如果还没有，先搭建好 AGV 路网并创建 ControlArea。

---

## 2. 创建红绿灯实体

### 2.1 从库中拖入

1. 打开 **Library（库）** → **Task Executers**
2. 将 **TaskExecuter** 拖入模型视图
3. 重命名为 `trafficlight1`（或你喜欢的名称）

### 2.2 调整外观（可选）

在属性面板中把 3D Shape 改小，方便放在路口旁。

---

## 3. 创建视觉子实体

红绿灯需要三个灯头（红/绿/黄），放在实体内部作为视觉显示。

### 3.1 操作步骤

1. 在 **Library → Visual** 中找到 **Plane**（或其他简单形状）
2. 按住 **Ctrl** 键，将 Plane 拖到 `trafficlight1` **上面**（放入内部成为子实体）
3. 在弹出的创建对话框中 **不要勾选任何选项**，直接点 **OK**
4. 重复以上步骤，共创建 **3 个子实体**

### 3.2 重命名

在左侧树形面板中展开 `trafficlight1`，将三个子实体分别重命名为：

```
trafficlight1
└── visual
    └── drawsurrogate
        ├── red      ← Plane 子实体，改名为 red
        ├── green    ← Plane 子实体，改名为 green
        └── yellow   ← Plane 子实体，改名为 yellow
```

> ⚠️ **关键**：名称必须拼写正确且**全小写**：`red`、`green`、`yellow`。脚本用 `find(">visual/drawsurrogate/red")` 来定位。

### 3.3 设置颜色初始值

在三个子实体各自的属性中，设置 **Color** 为灰色，作为复位状态：
- red：`(0.5, 0.5, 0.5)` — 灰
- green：`(0.5, 0.5, 0.5)` — 灰
- yellow：`(0.5, 0.5, 0.5)` — 灰

## 4. 添加标签

在 `trafficlight1` 的属性面板中，找到 **Labels** 区域，添加以下标签：

| 标签名 | 类型 | 初始值 | 说明 |
|--------|------|--------|------|
| `绿灯时长` | Number | `23` | 绿灯持续秒数 |
| `黄闪时长` | Number | `3` | 黄灯持续秒数 |
| `红灯时长` | Number | `68` | 红灯持续秒数 |
| `偏移时间` | Number | `0` | 相位偏移秒数 |
| `phase` | String | `GREEN` | 当前相位 |
| `lockerName` | Pointer | （稍后绑定） | 指向 Locker |
| `groupName` | Pointer | （稍后绑定） | 指向 Group |

### 标签添加方式

1. 在 `trafficlight1` 属性面板中，找到 **Labels** 表
2. 点 **Add** 按钮
3. 输入标签名（中文）
4. 选择类型（Number / String / Pointer）
5. 填入初始值
6. 重复以上步骤添加全部 7 个标签

> ⚠️ `lockerName` 和 `groupName` 类型选 **Pointer**，先留空，步骤 9 再绑定。

## 5. OnReset 触发器

复位时所有灯变灰色，phase 重置为 GREEN。

在 `trafficlight1` 属性面板中，找到 **Triggers → OnReset**，粘贴以下代码：

```cpp
Object light = ownerobject(c);
setlabelstr(light, "phase", "GREEN");

Object red = light.find(">visual/drawsurrogate/red");
Object green = light.find(">visual/drawsurrogate/green");
Object yellow = light.find(">visual/drawsurrogate/yellow");

red.color = Color(0.5, 0.5, 0.5);
green.color = Color(0.5, 0.5, 0.5);
yellow.color = Color(0.5, 0.5, 0.5);
```

**说明**：
- `ownerobject(c)` — 获取当前灯实体本身
- `find(">visual/drawsurrogate/red")` — 在子实体树中定位红灯形状
- 灰色 `(0.5, 0.5, 0.5)` 表示复位状态

## 6. OnModelStart 触发器

模型启动时根据偏移时间计算初始相位，设置初始颜色，启动消息循环。

在 `trafficlight1` 属性面板中，找到 **Triggers → OnModelStart**，粘贴以下代码：

```cpp
Object light = ownerobject(c);

double greenDur = getlabelnum(light, "绿灯时长");
double flashDur = getlabelnum(light, "黄闪时长");
double redDur = getlabelnum(light, "红灯时长");
double offset = getlabelnum(light, "偏移时间");

double totalCycle = greenDur + flashDur + redDur;
double t = fmod(offset, totalCycle);

string state;
double remaining;

if (t < greenDur) {
    state = "GREEN";
    remaining = greenDur - t;
} else if (t < greenDur + flashDur) {
    state = "YELLOW";
    remaining = (greenDur + flashDur) - t;
} else {
    state = "RED";
    remaining = totalCycle - t;
}

setlabelstr(light, "phase", state);

// 设置初始颜色
Object red = light.find(">visual/drawsurrogate/red");
Object green = light.find(">visual/drawsurrogate/green");
Object yellow = light.find(">visual/drawsurrogate/yellow");

red.color = Color(0.3, 0, 0);
green.color = Color(0, 0.3, 0);
yellow.color = Color(0.3, 0.3, 0);

if (state == "GREEN") green.color = Color(0, 1, 0);
if (state == "YELLOW") yellow.color = Color(1, 1, 0);
if (state == "RED") red.color = Color(1, 0, 0);

senddelayedmessage(light, remaining, current);
```

**说明**：
- 从标签读取四个参数
- `fmod(offset, totalCycle)` 计算当前时间在周期内的位置
- 根据位置确定 state（GREEN / YELLOW / RED）
- 先全部设暗（`0.3`），然后当前状态对应颜色设亮
- `senddelayedmessage` 启动消息循环，在 `remaining` 秒后触发 OnMessage

## 7. OnMessage 触发器

核心逻辑：状态切换 + 颜色变化 + 锁定/释放 ControlArea。

在 `trafficlight1` 属性面板中，找到 **Triggers → OnMessage**，粘贴以下代码：

```cpp
Object light = ownerobject(c);
string state = getlabelstr(light, "phase");

double greenDur = getlabelnum(light, "绿灯时长");
double flashDur = getlabelnum(light, "黄闪时长");
double redDur = getlabelnum(light, "红灯时长");

string nextState;
double delay;

if (state == "GREEN") {
    nextState = "YELLOW";
    delay = flashDur;
} else if (state == "YELLOW") {
    nextState = "RED";
    delay = redDur;
} else {
    nextState = "GREEN";
    delay = greenDur;
}

setlabelstr(light, "phase", nextState);

// ===== 颜色控制 =====
Object red = light.find(">visual/drawsurrogate/red");
Object green = light.find(">visual/drawsurrogate/green");
Object yellow = light.find(">visual/drawsurrogate/yellow");

red.color = Color(0.3, 0, 0);
green.color = Color(0, 0.3, 0);
yellow.color = Color(0.3, 0.3, 0);

if (nextState == "GREEN") {
    green.color = Color(0, 1, 0);
}
if (nextState == "YELLOW") {
    yellow.color = Color(1, 1, 0);
}
if (nextState == "RED") {
    red.color = Color(1, 0, 0);
}

// ===== 必须放在占用逻辑之前！否则消息循环会被打断 =====
senddelayedmessage(light, delay, current);

// ===== 占用逻辑 =====
Object locker = getlabel(light, "lockerName");
Object grp = getlabel(light, "groupName");

if (locker && grp) {
    Group theGroup = Group(grp.name);

    // 离开 GREEN → 锁定该方向所有 ControlArea
    if (state == "GREEN") {
        for (int i = 1; i <= theGroup.length; i++) {
            Object caObj = theGroup[i];
            if (!caObj) continue;

            AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);

            int alreadyLocked = 0;
            for (int j = 1; j <= ca.allocations.length; j++) {
                AGV.AllocationPoint ap = ca.allocations[j];
                if (string(ap.allocator.name) == locker.name) { alreadyLocked = 1; break; }
            }
            if (!alreadyLocked) {
                for (int j = 1; j <= ca.requests.length; j++) {
                    AGV.AllocationPoint ap = ca.requests[j];
                    if (string(ap.allocator.name) == locker.name) { alreadyLocked = 1; break; }
                }
            }

            if (!alreadyLocked) {
                ca.allocate(locker, 1);
            }
        }
    }

    // 进入 GREEN → 释放该方向所有 ControlArea
    if (nextState == "GREEN") {
        for (int i = 1; i <= theGroup.length; i++) {
            Object caObj = theGroup[i];
            if (!caObj) continue;

            AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);

            // 倒序遍历（deallocate 会改变数组长度）
            for (int j = ca.allocations.length; j >= 1; j--) {
                AGV.AllocationPoint ap = ca.allocations[j];
                if (string(ap.allocator.name) == locker.name) {
                    ap.deallocate();
                }
            }
            for (int j = ca.requests.length; j >= 1; j--) {
                AGV.AllocationPoint ap = ca.requests[j];
                if (string(ap.allocator.name) == locker.name) {
                    ap.deallocate();
                }
            }
        }
    }
}
```

### 代码逻辑详解

| 部分 | 逻辑 |
|------|------|
| 状态切换 | GREEN→YELLOW→RED→GREEN，从标签读对应时长 |
| 颜色 | 先全部设暗，再点亮对应状态颜色 |
| `senddelayedmessage` | **必须在占用逻辑之前**，保证消息循环不中断 |
| 锁定（state=="GREEN"） | 离开绿灯时锁定该方向所有 ControlArea |
| 释放（nextState=="GREEN"） | 进入绿灯时释放该方向所有 ControlArea |
| 名称比较 | 用 `string(ap.allocator.name)` 而非直接 `==` 比较对象引用 |
| 倒序遍历 | `j--` 防止 deallocate 后索引错位 |

## 8. 创建 Locker 和 Group

Locker 是 AGV 系统中的"锁"，Group 是该方向涉及的 ControlArea 集合。

### 8.1 创建 Locker

1. 在 **Library → AGV** 中找到 **Resource**，拖入模型
2. 重命名为 `TrafficLightLocker_1`（对应方向 1）
3. 不需要修改其他属性

### 8.2 创建 Group

1. 在 **Toolbox** 中找到 **Group**（或从 Library 拖入）
2. 重命名为 `TrafficLight_1_CA_Group`（或你喜欢的名称）
3. 将属于这个方向的所有 **ControlArea** 拖入该 Group

> 每个方向有多少 ControlArea 取决于你的路网设计。确保一个方向的停车/冲突区域都在同一个 Group 中。

## 10. 初始化脚本

模型启动时，所有方向的 ControlArea 需要被预先锁定（全红状态），防止启动瞬间 AGV 闯进路口。

### 10.1 找到 Resume 触发器

1. 点击模型空白处，确保选中了 **Model**
2. 在属性面板中找到 **Triggers → OnModelReset** 或 **State → OnStartReset**
3. 粘贴以下代码（按你的方向数量调整）：

### 两方向示例（NS + EW）

```cpp
Object nsLocker = Model.find("TrafficLightLocker_NS");
Object ewLocker = Model.find("TrafficLightLocker_EW");

if (!nsLocker) {
    return 0;
}
if (!ewLocker) {
    return 0;
}

Group nsGroup = Group("NS_Stop_CA_Group");
Group ewGroup = Group("EW_Stop_CA_Group");

// 锁定 NS 组
for (int i = 1; i <= nsGroup.length; i++) {
    Object caObj = nsGroup[i];
    if (!caObj) continue;

    AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);

    int alreadyLocked = 0;
    for (int j = 1; j <= ca.allocations.length; j++) {
        if (ca.allocations[j].allocator == nsLocker) { alreadyLocked = 1; break; }
    }
    if (!alreadyLocked) {
        for (int j = 1; j <= ca.requests.length; j++) {
            if (ca.requests[j].allocator == nsLocker) { alreadyLocked = 1; break; }
        }
    }
    if (!alreadyLocked) {
        ca.allocate(nsLocker, 1);
    }
}

// 锁定 EW 组
for (int i = 1; i <= ewGroup.length; i++) {
    Object caObj = ewGroup[i];
    if (!caObj) continue;

    AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);

    int alreadyLocked = 0;
    for (int j = 1; j <= ca.allocations.length; j++) {
        if (ca.allocations[j].allocator == ewLocker) { alreadyLocked = 1; break; }
    }
    if (!alreadyLocked) {
        for (int j = 1; j <= ca.requests.length; j++) {
            if (ca.requests[j].allocator == ewLocker) { alreadyLocked = 1; break; }
        }
    }
    if (!alreadyLocked) {
        ca.allocate(ewLocker, 1);
    }
}

return 0;
```

> ⚠️ 把 `TrafficLightLocker_NS`、`TrafficLightLocker_EW`、`NS_Stop_CA_Group`、`EW_Stop_CA_Group` 替换为你模型中的实际名称。

### 11.1 单个灯测试

1. 点击 **Run** 运行模型

## 12. 复制模块适配多路口

一个灯模块做成后，复制适配其他路口：

### 12.1 复制实体

1. 在模型树中右键 `trafficlight1` → **Copy**
2. 右键空白处 → **Paste**
3. 重命名为 `trafficlight2`

### 12.2 修改标签值（只需改这些！）

| 标签 | 操作 |
|------|------|
| `绿灯时长` | 填入新路口的绿灯秒数 |
| `黄闪时长` | 填入新路口的黄灯秒数 |
| `红灯时长` | 填入新路口的红灯秒数 |
| `偏移时间` | 填入新路口的相位偏移 |
| `lockerName` | 拖入新路口的 Locker |
| `groupName` | 拖入新路口的 Group |

### 12.3 偏移时间计算公式

```
总周期 = 绿灯时长 + 黄闪时长 + 红灯时长

灯1 偏移 = 0
灯2 偏移 = 灯1 绿灯 + 灯1 黄闪
灯3 偏移 = 灯2 偏移 + 灯2 绿灯 + 灯2 黄闪
...
```

### 12.4 更新初始化脚本

在初始化脚本中为新方向添加锁定代码，仿照 NS/EW 的写法复制一份即可。

## 13. 常见问题排查

### Q1: 灯不亮/不变色

- 检查子实体名称是否精确为 `red`/`green`/`yellow`（全小写）
- 确认子实体位置路径：`>visual/drawsurrogate/xxx`
- 查看控制台是否有报错

### Q2: "Invalid down cast" 错误

- **原因**：遍历 Group 时用了 `subnodes` 而非成员索引
- **修复**：用 `Group(grp.name)` + `theGroup[i]`，不要用 `.subnodes`

### Q3: LOCKED 打印了两遍

- **原因**：`ap.allocator == locker` 引用比较失败（指针标签拿到的引用和 init 时不同）
- **修复**：用 `string(ap.allocator.name) == locker.name` 进行名称比较

### Q4: "deallocate" / "free" unknown command

- **原因**：不能在 `AGV.AllocatableObject` 上直接调 deallocate
- **修复**：在 `AGV.AllocationPoint` 上调用：`ap.deallocate()`
- **注意**：遍历必须倒序（`j--`），因为 deallocate 会改变数组长度

### Q5: 颜色循环中断

- **原因**：`senddelayedmessage` 放在了占用逻辑后面，消息循环被打断
- **修复**：`senddelayedmessage` 必须在占用逻辑**之前**

### Q6: 复位后灯不亮

- 检查 OnReset 是否将 phase 设为 `GREEN`
- 确认 OnModelStart 正确计算了初始状态

### Q7: AGV 在绿灯时仍然等待

- 检查 `lockerName` 和 `groupName` 指针标签是否正确绑定
- 确认 Group 中包含正确的 ControlArea
- 查看控制台是否有 UNLOCKED 日志

### Q8: 多个灯同时为 GREEN

- 检查每个灯的 `偏移时间` 标签值是否正确
- 验证 `总周期 = 绿灯 + 黄闪 + 红灯` 对于所有灯是否一致

## 14. 配时设置（通用方法）

给灯设置配时标签（无需写代码，只改数值）：

1. 创建灯实体（数量 = 该路口相位方向数）
2. 填入标签：`绿灯时长`、`黄闪时长`、`全红时长`（五态用）、`红灯时长`、`偏移时间`、`phase`、`lockerName`、`groupName`
3. 绑定每个灯对应方向的 Locker 和 Group（`lockerName`/`groupName` 指针标签）
4. 在 Model 初始化脚本中按方向预先锁定所有 ControlArea

> **偏移时间、周期、红灯时长的计算公式与校验方法见 [配时逻辑与标签详解](配时逻辑与标签详解.md)**——周期和偏移是"算"出来的，不是拍脑袋填的。

## 附录：状态机

```
GREEN ──黄闪时长──► YELLOW ──红灯时长──► RED ──绿灯时长──► GREEN
  │                    │                    │
  ▼                    ▼                    ▼
 释放锁              锁定锁              锁定锁
 AGV通行             AGV禁行             AGV禁行
```

颜色：
| 状态 | 灯色 | 颜色代码 | 占用 |
|------|------|----------|------|
| GREEN | 🟢 绿灯 | `Color(0, 1, 0)` | 释放 ControlArea |
| YELLOW | 🟡 黄灯 | `Color(1, 1, 0)` | 锁定 ControlArea |
| RED | 🔴 红灯 | `Color(1, 0, 0)` | 锁定 ControlArea |
| 复位 | ⚪ 灰色 | `Color(0.5, 0.5, 0.5)` | — |
| 灭灯 | ⚫ 暗色 | `Color(0.3, r, g, b)` | — |
