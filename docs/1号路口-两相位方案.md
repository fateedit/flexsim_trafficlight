# 1号路口 — 两相位红绿灯方案

## 概述

两相位路口，2个独立灯控制南北/东西方向交替放行。94s周期。

## 路口参数

| 方向 | 绿灯 | 黄灯 | 红灯 | 总周期 |
|------|------|------|------|--------|
| 南北 | 23s | 3s | 68s | **94s** |
| 东西 | 20s | 3s | 71s | **94s** |

## 实体结构

```
TrafficLight_1_NS (TaskExecuter)        TrafficLight_1_EW (TaskExecuter)
├── red    (drawsurrogate)               ├── red    (drawsurrogate)
├── green  (drawsurrogate)               ├── green  (drawsurrogate)
└── yellow (drawsurrogate)               └── yellow (drawsurrogate)
```

## 标签

在 TrafficLight_1_NS 上：

| 标签名     | 类型     | 值     |
| ------- | ------ | ----- |
| `绿灯时长`  | number | 23    |
| `黄闪时长`  | number | 3     |
| `红灯时长`  | number | 68    |
| `偏移时间`  | number | 0     |
| `phase` | string | GREEN |

在 TrafficLight_1_EW 上：

| 标签名 | 类型 | 值 |
|--------|------|----|
| `绿灯时长` | number | 20 |
| `黄闪时长` | number | 3 |
| `红灯时长` | number | 71 |
| `偏移时间` | number | 26 |
| `phase` | string | GREEN |

> EW 偏移 = NS绿灯(23) + NS黄闪(3) = 26s，与 NS 错开放行。

## 全局函数 setLightColor

在 Model → Scripts → Global Code 中定义（所有路口共用，只需定义一次）：

```cpp
void setLightColor(Object light, string state) {
    treenode redLight = light.find("red");
    treenode greenLight = light.find("green");
    treenode yellowLight = light.find("yellow");

    if (state == "GREEN") {
        if (greenLight) greenLight.color = Color(0, 1, 0, 1);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 0.3);
        if (redLight) redLight.color = Color(1, 0, 0, 0.3);
    } else if (state == "YELLOW") {
        if (greenLight) greenLight.color = Color(0, 1, 0, 0.3);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 1);
        if (redLight) redLight.color = Color(1, 0, 0, 0.3);
    } else {  // RED
        if (greenLight) greenLight.color = Color(0, 1, 0, 0.3);
        if (yellowLight) yellowLight.color = Color(1, 1, 0, 0.3);
        if (redLight) redLight.color = Color(1, 0, 0, 1);
    }
}
```

## 脚本

状态序列：`GREEN(绿灯) → YELLOW(黄闪) → RED(红灯) → GREEN → ...`

### OnModelStart（两灯通用）

```cpp
double greenDur = labels["绿灯时长"].value;
double flashDur = labels["黄闪时长"].value;
double redDur = labels["红灯时长"].value;
double offset = labels["偏移时间"].value;

double totalCycle = greenDur + flashDur + redDur;
double t = fmod(offset, totalCycle);
Object light = ownerobject(c);

string state;
double remaining;

if (t < greenDur) {
    state = "GREEN";
    remaining = greenDur - t;
} else if (t < greenDur + flashDur) {
    state = "YELLOW";
    remaining = (greenDur + flashDur) - t;
} else {
    state = "RED";
    remaining = totalCycle - t;
}

light.labels["phase"].value = state;
setLightColor(light, state);
senddelayedmessage(light, remaining, current, state);
```

### OnMessage（两灯通用）

```cpp
Object light = ownerobject(c);
string state = msgparam(1);

double greenDur = light.labels["绿灯时长"].value;
double flashDur = light.labels["黄闪时长"].value;
double redDur = light.labels["红灯时长"].value;

string nextState;
double delay;

if (state == "GREEN") {
    nextState = "YELLOW";
    delay = flashDur;
} else if (state == "YELLOW") {
    nextState = "RED";
    delay = redDur;
} else {
    nextState = "GREEN";
    delay = greenDur;
}

light.labels["phase"].value = nextState;
setLightColor(light, nextState);
senddelayedmessage(light, delay, current, nextState);
```

### OnReset（两灯通用）

```cpp
Object light = ownerobject(c);
light.labels["phase"].value = "GREEN";

treenode redLight = light.find("red");
treenode greenLight = light.find("green");
treenode yellowLight = light.find("yellow");

if (greenLight) greenLight.color = Color(0.5, 0.5, 0.5, 1);
if (yellowLight) yellowLight.color = Color(0.5, 0.5, 0.5, 1);
if (redLight) redLight.color = Color(0.5, 0.5, 0.5, 1);
```

## 占用逻辑

### 资源

| Locker 名称 | Group 名称 | 控制区域 |
|-------------|-----------|---------|
| `TrafficLightLocker_NS` | `NS_Stop_CA_Group` | 南北方向所有冲突区域 |
| `TrafficLightLocker_EW` | `EW_Stop_CA_Group` | 东西方向所有冲突区域 |

### 初始化锁定

模型启动时将所有方向设为 ALL_RED 并锁定，在某个初始化触发器（如 Model 的 OnModelStart 或单独控制脚本）中执行：

```cpp
// ===== 灯设为全红 =====
string lightNames[2] = {"TrafficLight_1_NS", "TrafficLight_1_EW"};
for (int i = 0; i < 2; i++) {
    Object light = Model.find(lightNames[i]);
    if (light) {
        light.labels["phase"].value = "ALL_RED";
    }
}

// ===== 锁定所有方向冲突区域 =====
string lockerNames[2] = {"TrafficLightLocker_NS", "TrafficLightLocker_EW"};
string groupNames[2] = {"NS_Stop_CA_Group", "EW_Stop_CA_Group"};

for (int k = 0; k < 2; k++) {
    Object locker = Model.find(lockerNames[k]);
    Group grp = Group(groupNames[k]);
    if (!locker) continue;

    for (int i = 1; i <= grp.length; i++) {
        Object caObj = grp[i];
        if (!caObj) continue;

        AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);
        int alreadyLocked = 0;

        for (int j = 1; j <= ca.allocations.length; j++) {
            if (ca.allocations[j].allocator == locker) {
                alreadyLocked = 1; break;
            }
        }
        if (!alreadyLocked) {
            for (int j = 1; j <= ca.requests.length; j++) {
                if (ca.requests[j].allocator == locker) {
                    alreadyLocked = 1; break;
                }
            }
        }
        if (!alreadyLocked) {
            ca.allocate(locker, 1);
            pt("Init: locked " + caObj.name + " by " + lockerNames[k] + "\n");
        }
    }
}
```

## ProcessFlow

2个并行子流程，各监听一个灯。

### 子流程_NS

```cpp
Object light = Model.find("TrafficLight_1_NS");
Object locker = Model.find("TrafficLightLocker_NS");
Group group = Group("NS_Stop_CA_Group");

while (true) {
    if (light.labels["phase"].value == "GREEN") {
        // 释放该方向所有冲突区域
        for (int i = 1; i <= group.length; i++) {
            Object caObj = group[i];
            if (caObj) caObj.as(AGV.AllocatableObject).deallocate(locker);
        }

        // 等待变为非 GREEN（YELLOW 即开始锁定）
        while (light.labels["phase"].value == "GREEN") {
            sleep(0.05);
        }

        // 锁定该方向所有冲突区域
        for (int i = 1; i <= group.length; i++) {
            Object caObj = group[i];
            if (!caObj) continue;
            AGV.AllocatableObject ca = caObj.as(AGV.AllocatableObject);

            int alreadyLocked = 0;
            for (int j = 1; j <= ca.allocations.length; j++) {
                if (ca.allocations[j].allocator == locker) {
                    alreadyLocked = 1; break;
                }
            }
            if (!alreadyLocked) {
                ca.allocate(locker, 1);
            }
        }
    }
    sleep(0.05);
}
```

### 子流程_EW

同上，把 `TrafficLight_1_NS` → `TrafficLight_1_EW`，`NS` → `EW`。

## 时序验证

```
 0s    23s  26s                    94s      117s  120s
 |     |    |                      |        |     |
[GREEN23][Y3][     RED 68s       ][ GREEN  ][Y3][RED...
[     RED 71s              ][GREEN20][Y3]      [ RED 71s...
                            26s      49s 52s
```

- NS 绿灯窗口：0~23s
- EW 绿灯窗口：26~46s（26s~46s = 20s ✓）
- 同一时刻南北/东西不会同时放行 ✓
