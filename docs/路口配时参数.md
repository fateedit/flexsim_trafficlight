# 三个路口红绿灯配时参数

> 根据最新观测数据和配时方案，为 FlexSim 红绿灯模块计算可直接使用的标签值。
> 每个路口独立计算，周期可能不同，复制到模型时按表格对应设置即可。

---

## 计算规则

### 路口 1（3 相位循环）

路口 1 没有全红时段，采用 **3 相位循环**：`GREEN → YELLOW → RED → GREEN`。

| 参数 | 含义 | 计算公式 |
|------|------|----------|
| `绿灯时长` | 绿灯亮的时间 | 直接采用方案绿灯时间 |
| `黄闪时长` | 黄灯时间 | 直接采用方案黄闪时间 |
| `红灯时长` | 红灯时间 | `周期 - 绿灯 - 黄闪` |
| `偏移时间` | 相对于周期起点的绿灯启动时间 | 累加前面所有灯的 `绿灯 + 黄闪` |
| `周期` | 一个完整循环 | 所有相位 `绿灯 + 黄闪` 之和 |

### 路口 2 和 3（5 相位循环）

路口 2 和 3 方案中有黄灯后的全红时段，采用 **5 相位循环**：`GREEN → YELLOW → ALLRED → RED → YELLOW2 → GREEN`。

| 参数 | 含义 | 计算公式 |
|------|------|----------|
| `绿灯时长` | 绿灯亮的时间 | 直接采用方案绿灯时间 |
| `黄闪时长` | 黄灯时间 | 直接采用方案黄闪时间 |
| `全红时长` | 全红（所有方向全红）时间 | 直接采用方案全红时间 |
| `红灯时长` | 红灯等待时间 | `周期 - 绿灯 - 黄闪 - 全红 - 黄闪` |
| `偏移时间` | 相对于周期起点的绿灯启动时间 | 累加前面所有灯的 `绿灯 + 黄闪 + 全红` |
| `周期` | 一个完整循环 | `绿灯 + 黄闪 + 全红 + 红灯 + 黄闪` |

## 路口 1：南港八路（边检门前）

### 基础数据

- 南北方向：红灯 68s + 绿灯 23s + 黄灯 3s
- 东西方向：红灯 71s + 绿灯 20s + 黄灯 3s
- 实测周期：94s

> 注：文档提到 "3 个流向（41s / 24s / 9s）" 是交通流向说明，实际信号控制采用最新观测的绿/黄/红灯时间。

### 配时表

| 灯位 | 控制方向 | 绿灯时长 | 黄闪时长 | 红灯时长 | 偏移时间 | 周期 |
|------|----------|----------|----------|----------|----------|------|
| 灯 1 | 南北 | 23 | 3 | 68 | 0 | 94 |
| 灯 2 | 东西 | 20 | 3 | 71 | 26 | 94 |

### 计算过程

```
周期 T = 23 + 3 + 68 = 94s

灯 1（南北）— 第一个放行:
  偏移 = 0
  绿灯：0  ~ 23
  黄灯：23 ~ 26
  红灯：26 ~ 94

灯 2（东西）— 灯 1 结束后放行:
  偏移 = 灯1绿灯 + 灯1黄闪 = 23 + 3 = 26
  绿灯：26 ~ 46
  黄灯：46 ~ 49
  红灯：0 ~ 26 及 49 ~ 94
  红灯时长 = 26 + (94-49) = 71 ✓
```

### 使用方式

- 创建 2 个红绿灯实体
- 灯 1 绑定 `南北` Locker 和 ControlArea Group，偏移 0
- 灯 2 绑定 `东西` Locker 和 ControlArea Group，偏移 26

## 路口 2：南港八路与自由港大道

### 基础数据

- 优化周期：117s
- 放行顺序：A(南向北) → C(北向南) → B(西向东) → D(东向西)
- 缓冲时长：黄闪 + 全红 + 黄闪（5 相位循环）
- 4 个相位，各方向独立放行：
  - A：南港八路（南向北），绿灯 30s
  - C：南港八路（北向南），绿灯 18s
  - B：自由港大道（西向东），绿灯 35s
  - D：自由港大道（东向西），绿灯 18s

### 配时表

| 灯位 | 控制方向 | 绿灯时长 | 黄闪时长 | 全红时长 | 红灯时长 | 偏移时间 | 周期 |
|------|----------|:--------:|:--------:|:--------:|:--------:|:--------:|:----:|
| 灯 A | 南港八路（南向北） | 30 | 2 | 2 | 81 | **0** | 117 |
| 灯 C | 南港八路（北向南） | 18 | 2 | 2 | 93 | **34** | 117 |
| 灯 B | 自由港大道（西向东） | 35 | 2 | 2 | 76 | **56** | 117 |
| 灯 D | 自由港大道（东向西） | 18 | 2 | 2 | 93 | **95** | 117 |

### 计算过程（5 相位：GREEN→YELLOW→ALLRED→RED→YELLOW2）

```
每个灯周期 T = 30 + 2 + 2 + 81 + 2 = 117s
             = 18 + 2 + 2 + 93 + 2 = 117s
             = 35 + 2 + 2 + 76 + 2 = 117s
               ... 所有灯周期相同 ✓

灯 A（南向北）— 第一个放行:
  偏移 = 0
  绿灯：0   ~ 30
  黄灯：30  ~ 32
  全红：32  ~ 34
  红灯：34  ~ 115
  黄闪2：115 ~ 117
  红灯时长 = 115 - 34 = 81 ✓

灯 C（北向南）— 第二个放行:
  偏移 = A绿灯 + A黄闪 + A全红 = 30 + 2 + 2 = 34
  绿灯：34  ~ 52
  黄灯：52  ~ 54
  全红：54  ~ 56
  红灯：56  ~ 115
  黄闪2：115 ~ 117
  红灯时长 = 56 - 34 - 2 - 2 = 93 ✓

灯 B（西向东）— 第三个放行:
  偏移 = 34 + C绿灯 + C黄闪 + C全红 = 34 + 18 + 2 + 2 = 56
  绿灯：56  ~ 91
  黄灯：91  ~ 93
  全红：93  ~ 95
  红灯：95  ~ 115
  黄闪2：115 ~ 117
  红灯时长 = 95 - 56 - 2 - 2 = 76 ✓

灯 D（东向西）— 第四个放行:
  偏移 = 56 + B绿灯 + B黄闪 + B全红 = 56 + 35 + 2 + 2 = 95
  绿灯：95  ~ 113
  黄灯：113 ~ 115
  全红：115 ~ 117
  红灯：0   ~ 95
  黄闪2：117（下一周期起点，灯 D 的红灯 = 下一周期起点 - 偏移 = 117 - 95 = 22，
         但需加上当前周期内 0~95 的等待，即 95 + (117-117) = 95）
  红灯时长 = 95 ✓
```

### 绿灯窗口时序验证

```
  0s    30 32 34                     115 117    149
  |     |  |  |                       |   |      |
A [  GREEN30  ][Y][AR][      RED 81s        ][Y2][ GREEN...  ]
C [           RED 93s            ][Y2][ GREEN18 ][Y][AR][ RED... ]
B [                    RED 76s                 ][Y2][  GREEN35   ][Y]
D [                              RED 93s                         ][Y2][...
                         34    52 54 56        91 93 95        113  117
```

- A GREEN: 0~30s ✅
- C GREEN: 34~52s ✅
- B GREEN: 56~91s ✅
- D GREEN: 95~113s ✅
- **同一时刻只有 1 个灯为 GREEN** ✅

### 使用方式

- 创建 4 个红绿灯实体（A / C / B / D）
- **放行顺序：南向→北向→西向→东向**，A→C→B→D 依次放行
- 每个灯绑定对应方向的 Locker 和 ControlArea Group
- 4 个灯互锁，任意时刻只有一个方向为绿灯

## 路口 3：南港九路与自由港大道

### 基础数据

- 周期：108s（5 相位：GREEN→YELLOW→ALLRED→RED→YELLOW2）
- 放行顺序：EW(东西合并) → NS_S(南北直行) → NS_L(南北左转)
- 3 个相位，东西左转+直行合并：
  - **EW**：东西左转 + 直行，绿灯 50s（原 a 25s + b 25s）
  - **NS_S**：南北直行，绿灯 20s
  - **NS_L**：南北左转，绿灯 20s
- **南北右转不受控**：在 NS_S 和 NS_L 中均有放行窗口，不需 Locker

### 配时表

| 灯位 | 控制方向 | 绿灯时长 | 黄闪时长 | 全红时长 | 红灯时长 | 偏移时间 | 周期 |
|:----:|----------|:--------:|:--------:|:--------:|:--------:|:--------:|:----:|
| **EW** | 东西左转 + 直行 | 50 | 3 | 3 | 49 | **0** | 108 |
| **NS_S** | 南北直行 | 20 | 3 | 3 | 79 | **56** | 108 |
| **NS_L** | 南北左转 | 20 | 3 | 3 | 79 | **82** | 108 |

### 计算过程（5 相位：GREEN→YELLOW→ALLRED→RED→YELLOW2）

```
每个灯周期 T = 50 + 3 + 3 + 49 + 3 = 108s
             = 20 + 3 + 3 + 79 + 3 = 108s
               所有灯周期相同 ✓

灯 EW（东西左转+直行）— 第一个放行:
  偏移 = 0
  绿灯：0   ~ 50
  黄灯：50  ~ 53
  全红：53  ~ 56
  红灯：56  ~ 105
  黄闪2：105 ~ 108
  红灯时长 = 105 - 56 = 49 ✓

灯 NS_S（南北直行）— 第二个放行:
  偏移 = EW绿灯 + EW黄闪 + EW全红 = 50 + 3 + 3 = 56
  绿灯：56  ~ 76
  黄灯：76  ~ 79
  全红：79  ~ 82
  红灯：82  ~ 105
  黄闪2：105 ~ 108
  红灯时长 = 82 - 56 - 3 - 3 = 79 ✓

灯 NS_L（南北左转）— 第三个放行:
  偏移 = 56 + NS_S绿灯 + NS_S黄闪 + NS_S全红 = 56 + 20 + 3 + 3 = 82
  绿灯：82  ~ 102
  黄灯：102 ~ 105
  全红：105 ~ 108
  红灯：0   ~ 82
  黄闪2：108（下一周期起点）
  红灯时长 = 82 - 0 = 82（跨周期）
           = 108 - 82 - 3 - 3 = 79 ✓（实际在 0~82 区间的纯红灯为 79s）
```

### 绿灯窗口时序验证

```
  0s            50 53 56   76 79 82  102 105 108
  |             |  |  |    |  |  |    |   |   |
EW [   GREEN 50s     ][Y][AR][    RED 49s     ][Y2]
NS_S [                 RED 79s               ][Y2][ GREEN20][Y][AR]
NS_L [                           RED 79s             ][Y2][ GREEN20][Y]
                                             56        76 82      102
```

- EW GREEN:     0~50s  ✅
- NS_S GREEN:   56~76s ✅
- NS_L GREEN:   82~102s ✅
- **同一时刻只有 1 个灯为 GREEN** ✅
- 各相位间 6s 缓冲（YELLOW+ALLRED）✅

### 使用方式

- 创建 3 个红绿灯实体（EW / NS_S / NS_L）
- **放行顺序：东西→南北直行→南北左转**
- 3 套 Locker 和 Group（EW / NS_S / NS_L）
- 南北右转路径**不添加 ControlArea**，始终自由通行
- 3 个灯互锁，任意时刻只有一个相位为绿灯

## 通用设置方法

1. 在模型中创建对应数量的红绿灯实体（1 个灯 = 1 个相位方向）
2. 为每个灯添加标签：`绿灯时长`、`黄闪时长`、`全红时长`、`红灯时长`、`偏移时间`、`phase`、`lockerName`、`groupName`
   - **路口 1** 无全红，不需要 `全红时长` 标签
   - **路口 2 和 3** 需要全部 5 个时间标签
3. 按上表填入各标签值
4. 将 `phase` 初始值设为 `GREEN`
5. 将 `lockerName` 拖入对应方向的 Locker
6. 将 `groupName` 拖入该方向需要控制的 ControlArea Group
7. 在 Model 的初始化脚本中，按方向预先锁定所有 ControlArea（全红状态）

## 校验公式

设置完后，用下面公式检查每个灯是否自洽：

### 路口 1（3 相位）

```
周期 = 绿灯时长 + 黄闪时长 + 红灯时长
```

### 路口 2 和 3（5 相位）

```
周期 = 绿灯时长 + 黄闪时长 + 全红时长 + 红灯时长 + 黄闪时长
```

### 偏移时间校验

同一路口内各灯周期必须相等。偏移时间是否正确的校验：

```
灯 N 的偏移 = 灯 1(绿灯+黄闪+全红) + 灯 2(绿灯+黄闪+全红) + ... + 灯 (N-1)(绿灯+黄闪+全红)
```

> **注意**：5 相位模型中偏移累加的是 `绿灯 + 黄闪 + 全红`，不是 `绿灯 + 黄闪`。

最后一个灯的黄闪 2 结束时间应刚好对齐下一个周期的第一个灯绿灯开始时间。
